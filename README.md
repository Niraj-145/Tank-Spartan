
# Tank-Spartan: Portal Siege

An action game built with React, TypeScript, and Vite.

## Tech Stack
- React 19
- TypeScript
- Vite
- Capacitor (Android)

## Run Locally

### Prerequisites
- Node.js
- npm

### Installation

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
